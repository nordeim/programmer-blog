# useScrollProgress

Returns a 0–1 number indicating how far the page has been scrolled.

## Usage

```tsx
import { useScrollProgress } from '@devlog/snippets';

const progress = useScrollProgress();

return (
  <div
    aria-hidden="true"
    style={{
      position: 'fixed',
      top: 0,
      left: 0,
      width: `${progress * 100}%`,
      height: '2px',
      background: 'var(--accent)',
    }}
  />
);
```

## Behaviour

- Uses `requestAnimationFrame` to throttle scroll events.
- Returns `0` on initial render, `1` at the bottom of the page.
- Cleans up listeners on unmount.
